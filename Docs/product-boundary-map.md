# Research/Product Boundary Map

GreyTheory AI × ChaseOS exists to convert safe security research into credible defensive products, public proof, and reusable ChaseOS/Chaser Agent safety patterns.

## Product lane thesis

GreyTheory should become a productized security research and agentic-system defense lane:

- credible technical research surface
- local-first defensive tooling
- repo-backed proof artifacts
- public-safe ChaseInTech content material
- future business packaging after proof exists

## Boundary map

| Area | Allowed now | Blocked until approval |
|---|---|---|
| Repo/docs | Snapshots, README, roadmap, architecture, schemas | Secrets, private customer data, unapproved exploit details |
| Local demos | Intentionally local toy apps, fixture data, defensive checks | Live targets, third-party systems, unauthorized probing |
| Agentic defense | Prompt-injection demos, authority maps, runtime safety checklists | Testing someone else's agent/system without permission |
| Vulnerability research | Literature notes, toy reproduction, detection logic design | Publishing exploit instructions for live systems |
| GitHub proof | Public-safe docs, issues, roadmap, demo screenshots | Sensitive artifacts, real target evidence, unapproved claims |
| Business packaging | Offer drafts, proof plan, product menus | Customer outreach, paid commitments, public launch without approval |

## First product surfaces

1. **AI Agent Authority Audit** — local checklist + report template.
2. **Prompt-Injection Readiness Review** — toy-demo proof and mitigation checklist.
3. **Agent Runtime Safety Pack** — permission boundary, approval gate, and audit template bundle.
4. **Repo/Docs Security Boundary Review** — static/local review package with no external probing.
5. **Safe Disclosure/Authorization Kit** — authority checklist and proof packet template.

## ChaseOS aid path

GreyTheory aids ChaseOS by producing reusable proof for:

- Hermes/OpenClaw/Chaser authority boundaries
- prompt-injection hardening
- approval-gated live actions
- repo-safe public proof posts
- Agent Skills / runtime security review templates
- future security-facing product offers
