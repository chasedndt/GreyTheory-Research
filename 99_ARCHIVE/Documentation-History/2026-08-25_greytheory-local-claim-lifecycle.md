# Documentation History - GreyTheory Governed Local Claim Lifecycle

- Date: 2026-08-25
- Runtime: Codex / Axiom-Codex
- Status: PARTIAL and VERIFIED locally

## Historical change

The default workbench can now complete the current-posture report-readiness
journey for the exact two-account fixture. It assembles seven claim roles by
rerunning deterministic validators over already-held evidence and deriving the
two judgement roles from persisted human attestations. The resulting finding
and report matrix are stored atomically, and claim assembly forces a fresh
validation run.

The lifecycle command derives the next internal state server-side, requires a
current Gates B-F pass for `report_ready`, and has no route into submission or
programme-owned outcomes. Private export now carries the digest-bound finding
and validator receipts. Broader passive claim assembly remains unbuilt.
