# Documentation History - GreyTheory Private Report Authoring

- Date: 2026-08-25
- Runtime: Codex / Axiom-Codex
- Status: PARTIAL and VERIFIED locally

## Historical change

The default workbench runtime gained persistent private finding/report-draft
cases. An operator can create an informational case from a testing or supported
persisted hypothesis and save complete draft prose against an optimistic
revision. Authority-bearing context and the claim matrix stay server-owned.

Claim-role bindings and validator receipts now survive serialisation, closing a
restart-corruption gap. Authoring remains distinct from validation: it cannot
promote a claim or finding, make a draft report-ready, export, or submit.
