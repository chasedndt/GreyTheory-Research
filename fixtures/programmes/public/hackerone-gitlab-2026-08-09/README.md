# HackerOne / GitLab Public Programme Bundle

This is a saved public-source fixture for GreyTheory Milestone 2. It is research
about authority, not research against a target.

- Retrieved: 2026-08-09
- Platform: HackerOne
- Programme: GitLab
- Programme page: <https://hackerone.com/gitlab?type=team>
- Scope export: <https://hackerone.com/teams/gitlab/assets/download_csv.csv>
- Operating authority compiled by GreyTheory: `LOCAL_FIXTURE`

The scope CSV is the public structured export served by HackerOne. The two
Markdown files are bounded operator extracts, not representations of the full
web pages. Their capture modes are recorded in `manifest.json` so an extract is
never mistaken for a verbatim page snapshot.

No GitLab asset was contacted while creating this bundle. The bundle is not
human-reviewed and grants nothing until the normal registry review gate is
completed. Even after review, its `LOCAL_FIXTURE` ceiling does not permit live
target interaction.
