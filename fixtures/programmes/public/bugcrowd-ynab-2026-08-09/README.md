# Bugcrowd / YNAB public programme bundle

This bundle is an offline capture of public programme-authority sources retrieved on 2026-08-09. It contains:

- an operator-structured extract of the two rendered Bugcrowd target groups;
- a bounded, paraphrased extract of the YNAB programme brief; and
- a bounded, paraphrased extract of Bugcrowd's linked Standard Disclosure Terms.

The target-group extract preserves the names and locations rendered in the public tables. It is labelled `operator_extract`, not an official Bugcrowd export.

Two source conflicts are intentionally unresolved: broad YNAB-owned-host wording versus the listed-target-only rule, and a production API mention versus the production-environment exclusion. The compiler must therefore return `BLOCKED` until a human records decisions. This fixture grants no live authority and must not be used to test YNAB or any other target.
